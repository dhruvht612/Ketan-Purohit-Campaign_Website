# Campaign images

Drop the campaign photos here with these exact filenames — the site picks them
up automatically. Until a file exists, that slot shows an on-brand gradient
placeholder (nothing breaks).

| Filename | Used on | Recommended |
|---|---|---|
| `ketan-portrait.jpg` | Hero, About section, carousel intro slide | Portrait crop, face near the top, ~1000×1250px |
| `campaign-flyer.jpg` | Pictures gallery (Campaign category) | The full flyer, portrait orientation |

Paths are configured in `src/content/site.json` (`images`) and
`src/content/slides.json` / `src/content/gallery.json`. Change the filenames
there if you prefer different names.
